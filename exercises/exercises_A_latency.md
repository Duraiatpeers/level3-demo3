# Exercises: Latency

**A1. Different question**
In `01_one_timing.py` change the question to a longer one (for example, ask for a full summary of the PX-200 maintenance steps). Does the latency change? Write down both numbers.

**A2. Bigger sample**
Change `repeats` to 20 in `02_ten_timings.py`. Run it twice. Which of average, p50 and p95 changes most between the two runs?

**A3. Find the bug**
Run `A3_find_the_bug.py`. The p95 it prints is wrong. Find the missing line and fix it.

**A4. Slowest question**
Add a fourth question to `03_slowest_question.py`, one that asks about a PX-100 service log. Is it slower or faster than the others?

**A5. Think**
A customer says "the assistant is sometimes very slow". The average latency is 2 seconds. Why might the average hide their problem? Which number would you check instead?
