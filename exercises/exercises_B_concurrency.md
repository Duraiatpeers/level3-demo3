# Exercises: Concurrency

**B1. Predict first**
Before you run `04_sequential_vs_parallel.py`, write down how many times faster you expect 5 at a time to be than one after another. Then run it. How close were you?

**B2. Change the workers**
Change `workers` in `04_sequential_vs_parallel.py` to 2, then to 10. Write the three results in a table. Does doubling the workers halve the time?

**B3. Find the bug**
Run `B3_find_the_bug.py`. It reports almost 0 seconds. Find the line that is in the wrong place and fix it.

**B4. Load levels**
Run `05_load_levels.py`. Write down p50 and p95 for each level. Which number rises faster as the load rises, p50 or p95?

**B5. Think**
Your manager asks, "can the assistant handle 50 people at once?" Name two things you would still need to know before answering, other than the numbers from this program.
